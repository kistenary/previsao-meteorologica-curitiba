# Previsão Meteorológica de Curitiba-PR

Projeto desenvolvido em Python para consulta, organização e análise de dados meteorológicos de Curitiba-PR.

Os dados são obtidos por meio da API Open-Meteo e atualizados sempre que o notebook é executado.

## Funcionalidades

- Consulta da previsão meteorológica dos próximos 7 dias
- Temperatura máxima e mínima
- Volume previsto de precipitação
- Probabilidade de chuva
- Identificação automática do dia mais quente
- Identificação do maior volume de chuva
- Identificação da maior probabilidade de precipitação
- Classificação simples da chance de chuva
- Gráficos de temperatura e precipitação

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Requests
- Open-Meteo API
- Google Colab

## Fonte dos dados

Os dados meteorológicos utilizados neste projeto são fornecidos pela Open-Meteo.

## Como executar

O projeto pode ser executado no Google Colab.

Ao executar todas as células do notebook, uma nova consulta é realizada e os dados da previsão são atualizados automaticamente.

## Observação

A classificação de chance de chuva utilizada neste projeto possui finalidade demonstrativa e não representa um alerta meteorológico oficial.

## Objetivo

Este projeto foi desenvolvido como parte do meu portfólio acadêmico, com foco na aplicação de Python para coleta, tratamento, análise e visualização de dados ambientais.
